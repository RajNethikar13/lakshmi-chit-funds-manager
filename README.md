# Lakshmi Chit Manager

Offline-first Android MVP for a personal chit-fund business.

## Included in V1
- Reusable chit templates
- Chit groups
- Member/customer records
- Payment ledger foundation
- Dashboard: groups, members, received, given, outstanding
- WhatsApp reminder launch with a pre-filled message
- Starter 25-month ₹16,000 template based on the supplied scheme image
- Separate ledger concept for auditability

## Build the APK from a phone
1. Create a GitHub repository from the files in this project.
2. Push this folder to the repository.
3. GitHub Actions will use the included workflow to build an Android APK.
4. Download the APK from the workflow's Artifacts section and install it on your Android phone.
